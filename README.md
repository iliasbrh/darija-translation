Transformer-based model to translate english to darija (moroccan arabic) in latin alphabet. A pdf report of the proejct is available in english and french.
To test the model (with the according tokenizer) : [HF Space](https://huggingface.co/ilias-brh/transformer-english-darija-arabizi)
To see the dataset generated : [HF Dataset](https://huggingface.co/datasets/ilias-brh/english-darija-arabizi-sentence-pairs)

Training took 4.5 hours on one A100 GPU. Further details in the project report.
